## Запуск проекта


1. Необходимое программное обеспечение:

   - Python 3.12 и выше

2.  Клонируйте репозиторий:

    ```bash
    git clone https://gitlab.irkat.ru/23199/course-structure.git
    cd course-structure
    ```

3.  Запустите виртуальное окружение:

    ```bash
    cmd
    cd project
    .venv\Scripts\activate.bat
    ```

4.  Установите необходимые библиотеки:

    ```bash
    pip install -r requirements.txt
    ```

5.  Настройте базу данных MySQL и укажите параметры подключения в music_shop/settings.py:

    ```python
        DATABASES = {
            'default': {
                'ENGINE': 'django.db.backends.mysql',
                'NAME': 'наименование_БД',
                'USER': 'имя_пользователя',
                'PASSWORD': 'пароль_пользователя',
                'HOST': 'адрес_хоста',
                'PORT': '3306',
                'OPTIONS': {
                    'charset': 'utf8mb4',
                },
            }
        }
    ```

6.  Выполните миграцию:
    
    ```bash
    python manage.py migrate
    ```

7.  Заполните данными базу данных:

    ```bash
    python manage.py fill_db
    ```

8.  Запустите сервер:

    ```bash
    python manage.py runserver
    ```

9.  После запуска сервера сайт будет доступен по адресу: http://127.0.0.1:8000/

10.  Для доступа к административной панели, авторизуйтесь на сайте с данными администратора:
    
    Логин: admin
    Пароль: admin123
